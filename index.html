Overview

What the Counter class does

The Counter class is a reusable JavaScript component that creates an interactive counter intergace. It automatically generates a display the current count value and three buttons: Increment, Decrement, and Reset. The class manages the counter's state and update the user interface according to the changes, including disabling the Decrement and Reset buttons when the count reaches zero.

What problems it solves

The Counter class solves the problem of creating multiple interactive counter components without duplicating code, instead of manually creating HTNL elements, event listeners, and state management for each counter instance, you can simply instanciate the Counter class with a selector and optional initial value. This approach promotes code reusability and maintainability, and follows object-oriented programming principles.

How to Use

Example HTML container markup:

<div id="counter-container"></div>

Example instantiation code:

import Counter from './counter.js';
const counter1 = new Counter('#counter-container1', 0);
const counter2 = new Counter('#counter-container2', 4);

Example HTML container markup:

  • selector(required): A CSS selector string that identifies the HTML container element where the counter will be mounted. This SHould match an existing element in your HTML (e.g. '#counter-container 1' or .counter-wrapper')
  • initialValue(optional): The initial value for the counter. If not provided, it defaults to 0. This parameter allows you to set the starting value for each counter instance.
