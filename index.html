Overview

What the Counter class does

The Counter class is a reusable JavaScript component that creates an interactive counter interface. It automatically generates a display showing the current count value along with three buttons: Increment, Decrement, and Reset. The class manages the counter's state and updates the UI accordingly, disabling the Decrement and Reset buttons when the count reaches zero.

What problems it solves

The Counter class solves the problem of creating multiple interactive counter components without duplicating code, instead of manually creating HTNL elements, event listeners, and state management for each counter instance, you can simply instanciate the Counter class with a selector and optional initial value. This approach promotes code reusability and maintainability, and follows object-oriented programming principles.

How to Use

Example HTML container markup:

<div id="counter-container"></div>

Example instantiation code:

import Counter from './counter.js';
const counter1 = new Counter('#counter-container1', 0);
const counter2 = new Counter('#counter-container2', 4);

Example HTML container markup:

  • selector (required): A CSS selector string identifying the HTML container where the counter will be mounted. It must match an existing element in your HTML (e.g. '#counter-container1' or '.counter-wrapper').
  • initialValue (optional): The starting value for the counter. Defaults to 0 if not provided.
